Scheduler

Applies on restart

Automates the Movies, TV and Watchlist sync jobs that create the virtual .mkv files.

06.1MKV Creation SchedulerRestart
After the first run of the Movie and TV library jobs, hundreds of .mkv files will be created and Plex will start scanning them. During that initial scan playback will be extremely slow or may time out, because Plex opens and closes files hundreds of times and congests the BitTorrent engine. Wait for the scan to finish before starting any streams.

07.2Tokens

An MCP token opens only the MCP server (/mcp) and its library tools: give it to agents such as Hermes or Claude Code. An API token opens the HTTP API, for custom clients and apps built on Tiramisu, the menu bar app and scripts. Neither can manage tokens or sign-in: that needs this page, signed in. Tokens do not expire; the value is shown once, when it is created.

07.3Browser sessions
Sessions last 30 days from the last visit. Changing the password signs out every other session.
07.3Before you enable it
1
Choose a username and a password
Single user. Stored as a bcrypt hash in tiramisu.db, never in config.json.
2
Create a token for each client first
Tokens can be created while access is open: configure Hermes, Claude Code, your apps, the menu bar app and scripts (Authorization: Bearer), then enable sign-in.
3
Forgot the password?
Stop the service, run tiramisu --reset-auth on the host and start it again (Docker: TIRAMISU_RESET_AUTH=1 for one start, then remove it). It clears the user, sessions and tokens and turns sign-in off.
07.4HTTPSRestart

Encrypts the Control Panel, the API and /mcp. Webhooks and calls from this machine keep working over http://; pages move to https://.
Certificate detailsAdv

Names or IPs added to the certificate, comma-separated. Docker: the host's IP or name, which the container cannot see.
Paths on the host. Renewed files are picked up within a minute, no restart. If they cannot be read, Tiramisu falls back to the local CA and logs [TLS] ERROR.
Apply & restart in the bar at the bottom to use these settings, or Discard to go back.
07.5Turn off sign-in
Removes the requirement for this port. The user and the tokens are kept, so turning it back on restores them. Asks for the password.

Your node's name and address, and the film you start watching: friends who have it can help. Nothing else about your library, your players or your settings.
